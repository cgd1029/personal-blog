## 快速开始

### 创建一篇新文章

``` bash
$ hexo new "My New Post"
```

更多信息：[写作说明](https://hexo.io/docs/writing.html)

### 启动本地服务器

``` bash
$ hexo server
```

更多信息：[服务器说明](https://hexo.io/docs/server.html)

### 生成静态文件

``` bash
$ hexo generate
```

更多信息：[生成说明](https://hexo.io/docs/generating.html)

### 部署到远程网站

``` bash
$ hexo deploy
```

更多信息：[部署说明](https://hexo.io/docs/one-command-deployment.html)
